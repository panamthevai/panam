⚡ PANAMTHEVAI CYBER APT SERVER

🤖 எங்களது சொந்த Vivo Y20G மொபைல் மற்றும் Termux மூலம் இயங்கும் பாதுகாப்பான தனிநபர் மிரர் சர்வர்.

🌐 1. இந்த சர்வரை உங்கள் Termux-ல் இணைக்க (Setup)

கீழே உள்ள கமாண்டை அப்படியே காப்பி செய்து உங்கள் Termux-ல் பேஸ்ட் செய்யவும்:

echo "deb [trusted=yes] https://github.io ./" > $PREFIX/etc/apt/sources.list.d/myserver.list && apt update

📦 2. கிடைக்கக்கூடிய டூல்ஸ்கள் (Available Packages)

🛠️ mytool v2.0

Vivo Y20G-ன் RAM, ஸ்டோரேஜ் மற்றும் சர்வர் அப்டேட்களை ஒரே கிளிக்கில் நிர்வகிக்கும் மாஸ்டர் டூல்.

apt install mytool -y && mytool

🐍 python Official Mirror

நமது சொந்த சர்வரில் இருந்து நேரடியாகப் பெறப்படும் அதிவேக பைதான் பேக்கேஜ்.

apt install python -y

🐙 git Official Mirror

கோடிங் மற்றும் கிட்ஹப் நிர்வாகத்திற்கான லோக்கல் கிட் இன்ஸ்டாலர்.

apt install git -y
